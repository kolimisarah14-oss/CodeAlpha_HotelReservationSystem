# CodeAlpha_HotelReservationSystem
A Java based Hotel reservation system featuring room booking , cancellation , room categories , payment simulation , and booking management

## ✨ Features

- 🔍 Search available rooms
- 🛏️ Book a room
- ❌ Cancel a reservation
- 📋 Display all bookings
- 💰 Display room prices
- 💾 Save booking details to a text file
- ⚠️ Handle invalid room numbers and already-booked rooms

## 🛠️ Technologies Used

- Java
- ArrayList
- Scanner
- FileWriter
- Exception Handling
- Classes & Objects
- Loops and Conditional Statements
- Switch Case

## ▶️ How It Works

When the program starts, the user gets a menu with options:

1. Search Available Rooms
2. Book a Room
3. Cancel Reservation
4. Display Bookings
5. Exit

The program allows users to select a room, enter customer details, confirm payment, and store the reservation.

## 📂 File Storage

Booking details are saved in:

`bookings.txt`

This helps practice basic **Java file handling**.
